About Me

I like systems programming and care a lot about performance — graphics and real-time rendering are where I'm strongest, but I've done low-level C++, DirectX pipelines, networked multiplayer, and engine tooling too. I'm a Master's student in CS at USC and work at the Institute for Creative Technologies on AI-driven virtual humans and real-time interaction. Happy on a graphics-focused team or a generalist team where someone needs to own the full stack.

What I Do

Systems & Performance

I write C++ that has to run fast — multithreading, memory, keeping things from falling over when there's a lot on screen. I've worked on engine resource management, animation pipelines, and networked multiplayer. I'd rather fix a perf bug than add another abstraction layer.

Software Engineering

I care about design that doesn't turn into spaghetti. OOP, design patterns, REST APIs — and I like when the system is thought through before we scale it. I've worked in Agile setups and prefer clear ownership over committees.

Graphics & Interactive Tech

Real-time 3D is my main thing. Shaders (HLSL/GLSL), DirectX 12, Vulkan, OpenGL — I like the pipeline side, making it fast and correct. I've also done XR and the kind of interactive tech where graphics and gameplay meet.
